# Диалог с ИИ на одной странице — Talking to AI

Двуязычная шпаргалка (RU/EN) для работы, учёбы и творчества. Вся суть эффективного диалога с искусственным интеллектом — на одной странице, с переключением языка и тёмной темой.

## Ссылки

- 🇷🇺 [Русская версия](https://jag999g.github.io/ai-dialogue-card/#ru)
- 🇬🇧 [English version](https://jag999g.github.io/ai-dialogue-card/#en)

## О проекте

Шпаргалка создана в со-творчестве человека и Gemini: человек определил структуру и содержание, а Gemini помог оформить и отполировать текст.

## Возможности

- Переключение языка RU/EN (кнопки в шапке или ссылки `#ru` / `#en`)
- Светлая и тёмная темы
- Адаптивная вёрстка для телефона, планшета и компьютера
- Никаких зависимостей, кроме CDN — работает прямо из браузера

## Локальный запуск

Просто откройте `index.html` в любом браузере.
